# Find My Phone - GPS Tracker Website

Static official website for the Find My Phone - GPS Tracker Android app.

## Files

- `index.html` - homepage with app positioning, feature sections, screenshots, and Google Play links.
- `privacy.html` - privacy policy page.
- `styles.css` - responsive site styling.
- `app-ads.txt` - authorized Google advertising seller declaration.
- `imgs/` - app icon, banner, and screenshots.

## Local Preview

Open `index.html` in a browser. No build step or package installation is required.

## Deployment

Deploy the repository as a static site. Keep `app-ads.txt` at the web root so ad platforms can verify it at:

```text
https://your-domain.example/app-ads.txt
```
