# Find My Phone - GPS Tracker 官方网站

这是 Find My Phone - GPS Tracker Android 应用的静态官方网站。

## 文件说明

- `index.html` - 首页，包含应用介绍、功能区块、截图和 Google Play 下载链接。
- `privacy.html` - 隐私协议跳转页，自动打开官方隐私协议链接。
- `styles.css` - 响应式网站样式。
- `app-ads.txt` - Google 广告授权销售方声明文件。
- `imgs/` - 应用图标、横幅图和截图。

## 本地预览

用浏览器打开 `index.html` 即可预览。无需构建步骤，也不需要安装依赖。

## 部署

将本仓库作为静态网站部署即可。请保持 `app-ads.txt` 位于网站根目录，方便广告平台通过以下地址验证：

```text
https://your-domain.example/app-ads.txt
```
